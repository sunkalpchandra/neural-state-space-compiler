# Skill: statistical-analysis

## Purpose
How numbers become claims in `nssc`. Aggregation across seeds, uncertainty intervals,
paired comparisons between models, and the honesty rules for small n.

## Relevant theory
- **Unit of replication**: the seed (n = 5, seeds 0–4). Trajectories within a seed are
  not independent replicates of the *training* process; they are averaged first into one
  number per (model, system, horizon, seed).
- **Point estimate + spread**: mean ± std over seeds (population std, `ddof=1`). Also
  report min/max when n = 5 — the reader can see the whole distribution.
- **Bootstrap CI**: percentile bootstrap over seeds (B = 10 000 resamples with
  replacement of the 5 per-seed values) for the mean; for n = 5 this is coarse (only 126
  distinct resamples) — say so. For per-trajectory metrics within a fixed model,
  bootstrap over trajectories is fine and much tighter, but it quantifies evaluation
  noise, not training variability; label which.
- **Paired comparisons**: models trained on the same seed share data order and
  initialisation stream → pair by seed. Wilcoxon signed-rank on the 5 paired differences
  has minimum achievable two-sided p = 0.0625 (n = 5); it *cannot* reach 0.05. Report
  the statistic and p anyway, and rely on effect size + CI of the paired difference. With
  n = 5, a sign test is 1/16 two-sided at best. Do not report "p < 0.05" from n = 5.
- **Effect size**: paired difference of NRMSE (absolute) and relative
  `(a − b)/b`; for many systems, count systems where the CI of the paired difference
  excludes 0.
- **Multiple comparisons**: 9 baselines × 10 systems × 8 horizons ≈ 720 cells. Use
  Holm correction if any p-values are reported; better, pre-specify the primary
  comparison (H1: compiled vs best large seq model at H ∈ {100, 250} recursive) and
  treat the rest as descriptive.
- **Chaotic systems**: report median and IQR of VPT over trajectories (heavy-tailed).
- **Divergence**: rollouts that hit NaN/inf or `‖x̂‖ > 10·max‖x‖` are counted as
  diverged; report the divergence fraction separately and treat their NRMSE as
  right-censored (do not drop them from means — that inflates the surviving average;
  either cap at a documented value or report fraction + conditional mean).

## Project-specific conventions
- `nssc.metrics.aggregate`:
  `aggregate_seeds(df, by=[...]) -> mean, std, n, ci_low, ci_high, min, max`;
  `paired_compare(df, model_a, model_b, metric, by=[...]) -> diff_mean, diff_ci,
  wilcoxon_stat, wilcoxon_p, n_pairs`.
- Tables in `results/tables/*.md|csv` generated by `scripts/make_tables.py`, columns:
  `system, model, mode, horizon, mean, std, ci95_low, ci95_high, n_seeds,
  diverged_frac, n_params`. Format `0.123 ± 0.045` in markdown; CSV keeps raw.
- Table caption line: "n = 5 seeds (0–4); ± is std over seeds; CI is percentile
  bootstrap (B = 10 000) over seeds; test split; mode = recursive."
- Warnings emitted (and written into the table footer) when n_seeds < 5 or when
  `diverged_frac > 0`.

## Implementation requirements
- All aggregation functions take tidy DataFrames and are pure (no I/O).
- Bootstrap uses `numpy.random.default_rng(seed=0)` for reproducibility.
- Wilcoxon via `scipy.stats.wilcoxon(..., zero_method="wilcox", alternative="two-sided")`;
  guard for all-zero differences (returns NaN with a warning).
- Unit tests: known inputs → known mean/std/CI; paired compare on identical models
  → diff 0, p NaN or 1; n = 5 minimal p check.
- Rounding only at presentation time (3 significant figures); raw values in CSV.

## Common failure modes
- Std with `ddof=0` over 5 seeds (understates spread).
- Reporting CI from bootstrap over trajectories as if it were training uncertainty.
- Dropping diverged seeds/trajectories before averaging.
- "Significant" from n = 5 Wilcoxon.
- Aggregating over systems with different scales without normalizing (NRMSE first, then
  aggregate; never raw MSE across systems).
- Best-of-seeds reported as mean.

## Validation checklist
- [ ] Per-seed values computed first; aggregation over seeds; n stated.
- [ ] mean ± std, plus bootstrap CI where a claim depends on it.
- [ ] Paired-by-seed comparison for A vs B; effect size + CI shown; p only with the
      n = 5 caveat.
- [ ] Divergence fraction reported and handled explicitly.
- [ ] Primary comparison pre-specified in the experiment config; others descriptive.
- [ ] Tables generated by script; footer carries n and CI method.
